# AWS MCP

Entry point to the AWS labs MCP servers. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/awslabs.core-mcp-server

Installs from the Camillia hub as `aws-mcp-f19cff`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
